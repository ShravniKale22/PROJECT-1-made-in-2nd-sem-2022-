Smart Dustbin Using Arduino Uno

I developed a Smart Dustbin project using an Arduino Uno, an Ultrasonic Sensor, a Servo Motor, male jumper wires, and female jumper wires. The main objective of this project was to create an automatic dustbin that opens its lid without physical contact, promoting better hygiene and cleanliness.

The ultrasonic sensor is used to detect the presence of a hand or object near the dustbin. When an object comes within a certain distance, the sensor sends signals to the Arduino Uno. The Arduino processes these signals and controls the servo motor accordingly. The servo motor then rotates to automatically open the lid of the dustbin. After a few seconds, the lid closes automatically when no object is detected.

Male and female jumper wires were used to establish proper electrical connections between all the components on the circuit. The project demonstrates the practical implementation of embedded systems, sensor technology, and automation using Arduino programming.

This smart dustbin system is useful in homes, offices, hospitals, and public places as it helps reduce direct contact with the dustbin lid and maintains hygiene
